# Monsterhulen

**Hver gang du går inn i hulen, er den litt annerledes. Hvert eventyr blir helt sitt eget.**

Monsterhulen er en norsk, barnevennlig eventyrmotor for fri rollelek mellom barn og forteller. Kart, møter, mysterier, redninger og puzzles genereres på nytt fra eventyr til eventyr, mens Helteboka kan ta med varige minner, venner, kjæledyr og ting videre.

## Aktiv baseline

- Produktnavn: **Monsterhulen**
- Lokal/verifisert release: **V0.12.3 Lasting Thing Identity Pass**
- Save schema: **state 12**
- Kanonisk storage key: `monsterhulen_v120`
- Legacy migration: `eventyrkryper_v100` og eldre nøkler leses automatisk
- Asset Contract: **2.4.0**
- Fysiske D6 brukes på bordet; appen registrerer bare `1-2`, `3-4`, `5-6`.

## GitHub-status

Repoet er prosjektets GitHub-hjem. Roadmap, status, migreringsspesifikasjon, TING-spesifikasjon og baseline-hashes ligger på `main`. Den komplette runtimepakken er verifisert lokalt, men full bulk-import av `index.html` + 116 binære runtime-assets er ikke ferdigstilt i repoet ennå. Repoet skal derfor ikke omtales som direkte deploybart før denne importen faktisk er fullført.
