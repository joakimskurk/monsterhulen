# Monsterhulen

**Hver gang du går inn i hulen, er den litt annerledes. Hvert eventyr blir helt sitt eget.**

Monsterhulen er en norsk, barnevennlig eventyrmotor for fri rollelek mellom barn og forteller. Kart, møter, mysterier, redninger og puzzles genereres på nytt fra eventyr til eventyr, mens Helteboka kan ta med varige minner, venner, kjæledyr og ting videre.
