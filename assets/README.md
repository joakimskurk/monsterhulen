# Assets (genererte bilder)

Mappen er tom til de første bildene er laget. Hva som skal lages, står i `content/assets.json`, og stilen står i `content/art-style.json`. Arbeidsflyten er beskrevet i `content/README.md` under «Assets».

Hvert bilde har sin egen fil (stien står i `file`), og ved siden av ligger en sporingsfil med samme navn og `.json` som forteller hvordan bildet ble laget. `npm run validate:content` sjekker begge.
