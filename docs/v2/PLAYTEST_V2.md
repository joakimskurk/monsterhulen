# Spilletest V2 ved bordet

Status: **MAL, IKKE BRUKT ENNÅ** (2026-10-28). Fyll ut én økt per seksjon nederst. Dette er bevis av typen *spilltest* (`TESTING.md`): det eneste som kan vise om løpene er gøy og forståelige for barnet.

Prototypen: `prototype/README.md`. Det automatiske beviser bare at løpene *kan* løses, ikke at de er gode.

## Før økta (5 min)

- [ ] `npm run check` er grønn.
- [ ] `npm run prototype:lan` kjører, og iPaden har koblet til (koden øverst på Forteller-siden).
- [ ] Velg **Kort** første gang. Bruk **Nytt hver gang** eller **Overrask meg**.
- [ ] Terning ligger på bordet.
- [ ] Har Helteboka innhold? Trykk **Lagre kopi** av og til.

## Etter økta (5 min)

1. Hvilket oppdrag og hvilken kode? Lengde?
2. Hvor lenge varte det? Hvor mange rom?
3. Forsto barnet hva figurene ville, ut fra tegnene? Hvilket tegn virket best, og hvilket virket dårligst?
4. Føltes kjeden som et eventyr eller som henting?
5. Regle, kiste, figur som satt fast, maskin som manglet en del: hvordan gikk det?
6. Hva gjorde barnet som du ikke hadde ventet?
7. Ville barnet spille ett løp til? Hva sa det om Helteboka?
8. Feil og ting som må endres (koden, tekst, regler):
