## Manual visual review finding
An early V1.1 attempt added a marker using `.tile.current::after`. Runtime rooms may span multiple map tiles, so this produced repeated markers inside one physical room. The marker was removed before repository acceptance. Current V1.1 uses the room-area highlight only.
